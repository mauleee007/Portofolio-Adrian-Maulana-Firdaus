Technical Highlights
⚡
N+1 Query Prevention via Batch Loading
Thread list responses load Labels, Assignees, and Attachments via a single sqlx.In batch query each — eliminating N+1 entirely and keeping endpoints fast at scale.
📋
Immutable System Event Logging
Every ticket status change auto-inserts a read-only system comment (is_system_event = true). These audit entries are fully protected from edit or delete by the API.
🎨
Debounced WebSocket Persistence
Whiteboard canvas updates are buffered in-memory and flushed to MySQL with a 3-second debounce timer. A final synchronous save runs on room teardown to prevent any data loss.
🔄
QC-to-Ticket Auto-Resolve Pipeline
When all QC form items pass, the system automatically transitions the linked ticket to resolved and inserts a system event comment — zero manual intervention required.
🔐
Centralized Error Middleware
All handlers return error instead of writing responses directly. ErrorMiddleware differentiates typed AppError (user-facing) from raw DB errors (500), preventing internal details from leaking.
🛡
Orphan File Protection on Delete
The DELETE /upload/{file_name} endpoint verifies a file is unclaimed before deletion. Returns 403 Forbidden if it still belongs to any ticket or user profile.
